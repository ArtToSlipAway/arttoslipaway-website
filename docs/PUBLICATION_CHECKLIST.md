# Проверка перед публикацией

Публикуется только содержимое каталога этой portfolio-версии. Нельзя загружать
родительскую рабочую папку: она может содержать исходные резервные копии и SSH-ключи.

- Проверьте список файлов перед каждым коммитом: `git status --short`.
- Не добавляйте настоящие `.env`, JSON сервисного аккаунта, ключи, дампы,
  журналы, заявки и пользовательские загрузки, даже если Git предлагает `-f`.
- Для GitHub создайте новую историю из очищенных исходников: не переносите
  историю рабочего сервера, где секреты могли остаться в старых коммитах.
- Выполните `python -m unittest discover -s tests -v`.
- Дополнительно проверьте каталог и историю специализированным сканером секретов.
  Проверка отдельных шаблонов не гарантирует отсутствие всех видов секретов.
- Запустите проект с отдельной пустой PostgreSQL и тестовыми данными.
- Проверьте главную, каталог, вход администратора и отправку тестовой заявки.
- Добавляйте скриншоты только без данных клиентов и административных секретов.

## Границы версии

Это исходный код и примеры запуска для портфолио, а не заверенный аудит
безопасности. Публикация на GitHub не разворачивает приложение и не меняет
работающий сайт. Медиафайлы и база с реальными данными не входят в поставку.

Лицензия открытого исходного кода намеренно не выбрана: решение о предоставлении
прав на использование кода остаётся за владельцем. Перед добавлением сторонних
изображений, шрифтов или моделей проверьте права на их распространение.
