Проверка файлов

Матрица ручной проверки загрузок. Цель — пройти все точки загрузки и убедиться, что изображения, видео, 3D-файлы и клиентские референсы корректно сохраняются, отображаются и не ломают страницы.

Медиа-библиотека

Базовая загрузка файлов в общий архив сайта.
jpg jpeg png webp gif mp4 mov webm glb gltf obj stl usdz
  • Где проверять
    /admin/media
  • Успех
    Файл появился в списке, превью отображается, ссылка открывается.
  • Ошибка
    Файл не должен ломать страницу и не должен сохраняться с опасным расширением.

Карусель главной

Загрузка медиа для карточек главной карусели.
jpg png webp mp4 mov glb
  • Где проверять
    /admin/carousel
  • Успех
    Файл загружается, можно выбрать карточку карусели, запись сохраняется.
  • Важно
    Публичную подмену досок включаем позже точечно, чтобы не ломать визуал главной.

Проекты / портфолио

Медиа внутри конкретного проекта.
jpg png webp mp4 mov glb
  • Где проверять
    /admin/projects → открыть проект → медиа проекта.
  • Успех
    Медиа появляется в админке проекта, на странице проекта и на карточке проекта.
  • Важно
    Первый активный файл используется как обложка карточки проекта.

Свободные эскизы

Эскизы, которые выводятся в верхней карусели страницы.
jpg png webp mp4 mov
  • Где проверять
    /admin/carousel → карточка: Свободные эскизы.
  • Публично
    /categories/free-sketches
  • Успех
    Эскиз появляется в карусели, кнопка “Хочу этот эскиз” ведёт в заявку.

Референсы клиента

Файлы, которые клиент прикладывает к заявке.
jpg jpeg png webp pdf
  • Где проверять
    /request
  • Админка
    /admin/leads
  • Успех
    Файл прикрепился к заявке и открывается из админки.

Что должно быть запрещено

Эти типы не должны проходить загрузку.
php py sh exe js html svg
  • Цель
    Сайт не должен принимать исполняемые и потенциально опасные файлы.
  • Следующий шаг
    После ручной проверки добавим единый строгий upload-policy на backend.

Тестовая последовательность

Этап Что сделать Что считается успехом
1. Медиа Загрузить jpg/png/webp, mp4 или mov, glb через /admin/media. Файл появился в медиа-библиотеке и открывается.
2. Карусель Загрузить картинку в /admin/carousel и выбрать “Свободные эскизы”. Файл появился в списке карусели.
3. Свободные эскизы Открыть /categories/free-sketches. Файл виден в верхней карусели.
4. Заявка Нажать “Хочу этот эскиз” и отправить тестовую заявку. В /admin/leads видно выбранный эскиз с миниатюрой.
5. Проект Добавить медиа в существующий проект. Медиа видно на странице проекта и в карточке проекта.
6. Референсы Отправить заявку с jpg/png/pdf. Файлы открываются из карточки заявки.
7. Запрет Попробовать загрузить .php/.sh/.html. Файл не принимается.
